# Support

Use GitHub Discussions for installation help, hardware questions, and design
discussion. Search existing threads first and include:

- output from `friday version`;
- the non-sensitive parts of `friday doctor`;
- Linux distribution and desktop session;
- GPU model, VRAM, and driver version;
- the exact command that failed.

Use GitHub Issues for reproducible defects. Remove API keys, control tokens,
home-directory names, transcripts, voice clips, browser data, and document
contents before posting logs.

Security problems belong in private vulnerability reporting, as described in
[SECURITY.md](SECURITY.md).
